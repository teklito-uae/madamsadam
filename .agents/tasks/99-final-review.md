# 99 — Final creative-director review

Depends on: everything

## Objective
Inspect the finished site as a creative director, not a developer, before calling it done. See [../../BRAND_GUIDELINES.md](../../BRAND_GUIDELINES.md#final-gut-check-creative-director-review).

## Checklist
- Does this feel luxurious?
- Does it feel cinematic?
- Does it feel like entertainment?
- Does it feel like UAE?
- Does it communicate photography and events?
- Does it communicate branding and digital?
- Does the site make people curious in the first 5 seconds?
- Does the first scroll communicate the CREATE / CONNECT / BECOME philosophy?
- Does the middle of the page demonstrate real capability (portfolio, services)?
- Does the final section make the visitor want to start a conversation?
- Does the motion feel expensive, not decorative?
- Would any section be mistaken for "Creative Agency Template #247"? (See [../../BRAND_GUIDELINES.md](../../BRAND_GUIDELINES.md#anti-patterns--never-do-these).)

## If anything fails this review
Identify the specific section and anti-pattern it's falling into, then redesign that section rather than patching it with more decoration.

## Sign-off
Record the outcome (pass/fail per checklist item) and any follow-up redesign tasks needed before this is considered shippable.
